## 1. 任务目标与基本思路

任务要求仅使用正常训练样本学习规律，在测试集上判断是否患病：

- 输入：每个样本的 6 个脱敏数值特征。
- 训练数据：全部为正常样本，不提供患病训练样本。
- 输出：异常分数和预测标签，`0` 表示正常，`1` 表示患病。

可以把任务理解成：先认识“正常样本通常是什么样”，再检查新样本与正常规律有多大差异。这属于只有正常训练数据的异常检测，也可称为新颖性检测或单类学习。

本项目采用的建模假设是：患病样本可能在特征空间中偏离正常样本。这个假设是否有效，需要通过实验评价；异常程度不能直接等同于医学诊断。

实现顺序为：

```text
读取并检查数据
    ↓
将正常训练数据划分为训练子集和验证集
    ↓
仅用训练子集拟合预处理与模型
    ↓
计算正常验证集的异常分数，确定阈值
    ↓
计算测试集异常分数，生成预测标签
    ↓
使用测试标签评价，保存指标、图表和配置
```

先跑通近邻距离基线，再比较 Isolation Forest 和 One-Class SVM。

## 3. 数据划分与预处理

### 3.1 固定划分

第一版约定将原始正常训练集按约 80% / 20% 随机划分，使用 `random_state=42`：

| 数据部分 | 样本数 | 用途 |
| --- | ---: | --- |
| 正常训练子集 | 1,471 | 拟合预处理与模型 |
| 正常验证集 | 368 | 校准异常阈值 |
| 原始测试集 | 1,933 | 最终评价 |

所有模型复用同一份划分，保存原始行索引。随机划分暂以样本相互独立为假设；如发现患者分组、重复记录或时间依赖，应先记录并调整划分方案。

### 3.2 预处理规则

1. 显式选择六个特征列，保持训练、验证与测试列顺序一致。
2. 检查列名、数据类型、缺失值、无穷大、常量列和重复记录。
3. 第一版使用 `StandardScaler`，仅在正常训练子集上拟合。
4. 使用同一个已拟合的标准化器转换训练子集、验证集和测试集。
5. 如需填补缺失值或增加其他预处理，也只允许从正常训练子集学习参数。

标准化可理解为：每列减去训练子集的均值，再除以该列的标准差，降低不同特征尺度对距离计算的影响。

不得合并训练集和测试集后重新划分或拟合预处理。不要仅因正常训练样本数值极端就直接删除；先核对原因并记录处理依据。原始 CSV 保持不变。

## 4. 模型方案

### 4.1 统一评分约定

所有方法统一输出一维连续异常分数 `anomaly_score`：**越大表示越异常**。

预测规则统一为：

```text
anomaly_score > threshold  → 预测 1（患病）
anomaly_score <= threshold → 预测 0（正常）
```

异常分数用于评价排序能力，预测标签用于评价某个固定阈值下的判断效果，两者分别保存。

### 4.2 近邻距离基线

直观理解：新样本如果离已知正常样本都很远，就更可疑。

- 使用正常训练子集建立近邻查询模型。
- 第一版固定 `k=5`，使用欧氏距离。
- 对验证或测试样本，查找正常训练子集中最近的 5 个邻居。
- 将这 5 个距离的平均值作为异常分数。

使用 `NearestNeighbors` 实现邻居查询，不使用需要类别标签投票的 KNN 分类器。验证与测试样本仅作为查询点，不加入参考邻居集合。

### 4.3 Isolation Forest

直观理解：通过随机切分观察样本是否容易被单独隔离。

初始参数约定为 `n_estimators=200`、`max_samples="auto"`、`contamination="auto"`、`random_state=42`。这些是可复现的起点，不是已验证的最佳参数。

使用 `-model.score_samples(X)` 统一为越大越异常的分数。最终标签由正常验证集阈值生成，不使用模型默认 `predict` 的判断结果。

### 4.4 One-Class SVM

直观理解：学习正常样本所在的区域，衡量新样本对该区域的偏离。

初始参数约定为 `kernel="rbf"`、`gamma="scale"`、`nu=0.05`。`nu` 是训练约束参数，不代表测试集患病比例，也不等同于最终阈值对应的误报比例。

使用 `-model.score_samples(X)` 作为异常分数，再使用正常验证集阈值生成标签。标准化器与其他方法一样仅在训练子集上拟合。

## 5. 阈值如何确定

第一版主实验预先固定分位数 `q=0.95`：

```text
validation_scores = 模型对正常验证集输出的异常分数
threshold = validation_scores 的第 95 百分位数
```

实现时明确记录分位数计算方法，例如 `numpy.quantile(..., method="linear")`。不同模型分别计算自己的阈值，复用的是分位数规则，而不是同一个阈值数值。

这个规则允许正常验证集中大约分数最高的 5% 被判为异常。由于有限样本、重复分数和分布差异，验证误报比例不一定恰好为 5%，测试正常样本的误报率也不保证为 5%。它不意味着测试集中应有 5% 的患病预测。

验证集没有患病样本，无法直接用它选择患病召回率或 F1 最好的模型。因此第一版固定模型参数和阈值规则，不以测试集结果调参。

阈值校准后保持模型和预处理不变。不要把验证集并回训练数据重训后继续沿用旧阈值；若改变拟合方案，需要重新设计独立的阈值校准流程。

可选敏感性分析预先固定 `q ∈ {0.90, 0.95, 0.975, 0.99}`，完整展示所有设置，并始终保留 `q=0.95` 的主实验结果。不得只挑选测试 F1 最高的分位数作为正式方案。

## 6. 评价指标与结果分析

始终将患病类别 `1` 视为正类。

| 指标 | 使用的输出 | 含义 |
| --- | --- | --- |
| AUROC | 连续异常分数 | 衡量正负样本的整体排序区分能力 |
| AUPRC | 连续异常分数 | 衡量 Precision–Recall 曲线下的面积 |
| AP | 连续异常分数 | Average Precision，作为补充排序指标 |
| Precision | 预测标签 | 预测患病者中实际患病的比例 |
| Recall | 预测标签 | 实际患病者中被找到的比例 |
| F1 | 预测标签 | Precision 与 Recall 的调和平均 |
| 混淆矩阵 | 预测标签 | 展示正常判对、误报、漏报与患病判对的数量 |

AUPRC 与 AP 分别命名和保存：本项目约定 AUPRC 使用 PR 曲线的梯形积分，AP 使用 `average_precision_score`，不将二者当成同一个数。AUROC、AUPRC 和 AP 均使用连续分数，不使用二值预测标签。

混淆矩阵固定 `labels=[0, 1]`，行表示真实标签、列表示预测标签：

```text
[[TN, FP],
 [FN, TP]]
```

其中 FP 为误报、FN 为漏报。Precision、Recall 和 F1 显式指定 `pos_label=1` 和 `zero_division=0`；若没有预测正样本，应在结果说明中记录。准确率可以作为补充，但不能作为唯一评价依据。
